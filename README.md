# Homebrew Tap

Homebrew formulae and casks from [Stoffberg](https://github.com/Stoffberg).

## Available

| Name | Type | Description |
|------|------|-------------|
| [keep](https://github.com/Stoffbergie/keep) | Formula | Files from your terminal, kept forever |
| [beam](https://github.com/Stoffbergie/beam) | Formula | Your localhost, on the internet |
| [hook](https://github.com/Stoffbergie/hook) | Formula | Webhooks, caught and replayed |
| [record](https://github.com/Stoffbergie/record) | Cask | Privacy-first activity tracker for macOS |

## Installation

```bash
brew install stoffbergie/tap/keep
brew install stoffbergie/tap/beam
brew install stoffbergie/tap/hook
brew install stoffbergie/tap/record
```

## Update

```bash
brew update
brew upgrade keep
brew upgrade beam
brew upgrade hook
brew upgrade record
```
